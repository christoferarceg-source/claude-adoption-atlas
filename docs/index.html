Methodology

About the data

Where the numbers come from

Country and state/province figures come from the Anthropic Economic Index (CC-BY), a privacy-preserving sample of Claude.ai conversations (Free, Pro and Max, plus Cowork from 2026), geolocated by IP address. Anthropic publishes aggregates only, never raw IPs or individual records. This site cannot see anything more granular than what Anthropic releases.

How fresh it is

A GitHub Action runs every day. It checks the dataset for new releases and rebuilds the site's data when one appears, and it refreshes the npm download counts. Anthropic publishes new geography data every few months, covering periods that ended weeks earlier. The period menu on the map shows exactly which months are available.

The two core measures

  • Share of global usage is a country's percentage of all geolocated conversations in the period.
  • Intensity (AUI, the Anthropic AI Usage Index) is that share divided by the country's share of the world's working-age (15–64) population. 1.0 means usage proportional to population, and 3.0 means three times more. It's recomputed from raw shares so every period is comparable. For recent periods it matches Anthropic's published index to ±0.01.

Estimated users and adoption

Anthropic doesn't publish user or account counts by country, so the atlas shows a range. It takes third-party estimates of Claude's global monthly users and splits them by each country's share of Claude.ai conversations. Adoption is those estimated users divided by working-age population.

  • The lower bound counts mobile-app users only, while the upper bound covers web and app. They differ by about 4×, so every figure is shown as a lower–upper range. The sources are listed under the adoption section on the Insights tab.
  • Conversations aren't people. Heavy-use countries such as the US, Australia and South Korea are likely overstated. Countries with lighter use per person, such as India, Indonesia and Nigeria, are likely understated.
  • Business customers (300,000+ according to Anthropic) and Claude Code users aren't split by country, because no public data supports it.
  • Estimates only appear for periods close to when the global totals were measured.

What isn't here

  • Cities. Anthropic's finest geography is ISO 3166-2 subdivisions: states, provinces and regions. No city-level data is published.
  • Claude Code and API usage by country. API traffic, which includes Claude Code, is published only as a global total. The npm download trend and the context figures on the Insights tab are the best available proxies.
  • Unsupported countries. Claude isn't available in China, Russia, Iran, North Korea, Syria or Cuba. They're hatched on the map, because their absence isn't low demand.
  • Small countries and regions below Anthropic's privacy thresholds aren't published. A missing value isn't a zero.

Caveats

  • The August 2025, November 2025 and February 2026 periods are one-week samples, while later periods are calendar months. Treat small period-to-period moves as noise.
  • Coding share (Software Development + DevOps topics) exists only in releases using the June 2026 schema, because earlier topic taxonomies aren't comparable.
  • State/province intensity (AUI) is published only for US states. Elsewhere the map shows each region's share of its country's usage.
  • Some state/province codes don't match a map shape. Those regions appear in the side panel list, marked "no map shape".
  • Regions are groupings made for this site. For example, Mexico is in Latin America, and Turkey and the Caucasus are in Europe & Central Asia.
